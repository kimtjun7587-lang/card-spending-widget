# 하루여유 시험판 0.1 — Galaxy A16 확인용

이 앱은 개인 개발 무료 시험판입니다. 롯데카드 공식 앱·제휴 상품이 아닙니다. 스토어 출시나 외부 모집은 하지 않았습니다.

## 기존 앱 보존

- 원본: `com.kimtjun.cardspendingwidget`
- 시험판: `com.kimtjun.cardspendingwidget.trial`
- 이름·아이콘·위젯에 `시험판` 표시. 설치 파일: `haruyeoyu-trial-0.1.apk`.
- 별도 Android UID와 내부 SQLite `spendable_trial_v1.db` 사용. 원본 설정·소비 기록을 읽거나 이전하지 않습니다.
- 원본 GitHub main을 수정하지 않으며 시험판 브랜치에서만 변경합니다.
- 기존 앱과 홈 위젯은 유지하세요. 기존 앱 삭제는 필요하지 않습니다.

## 설치

1. APK를 Galaxy A16에 내려받습니다. ZIP을 받았다면 압축을 풉니다.
2. `haruyeoyu-trial-0.1.apk`를 누릅니다. 파일을 연 앱의 '이 출처 허용' 요청이 나오면 이번 설치를 위해 허용합니다. 설치 후 다시 끌 수 있습니다.
3. 삼성 보안 설정·회사 관리 정책이 설치를 차단하면 표시되는 문구를 확인하세요. 관리자가 설정한 제한을 우회하지 마세요. 기기 설정에 따라 설치 가능 여부가 달라집니다.
4. 앱 목록에서 **하루여유 시험판**을 실행합니다. 기존 **카드 소비 위젯**도 그대로 있는지 확인합니다.
5. 설치 화면이 기존 앱의 '업데이트'라고 표시되거나 기존 앱 삭제를 요구하면 진행하지 말고 파일명을 확인하세요. 이 APK는 다른 앱입니다.

## 처음 설정

1. 소비주기 예산과 매월 시작일을 입력합니다. 27일이면 27일~다음 달 26일. 29~31일이 없는 달은 말일을 사용합니다.
2. 현재 소비주기 전체 사용액 → 그중 이번 주 사용액 → 그중 오늘 사용액을 입력합니다. 세 값을 더하는 구조가 아닙니다.
   - 예: 주기 100,000원, 주간 30,000원, 오늘 5,000원 → 전체 사용액은 **100,000원**.
   - 주기 ≥ 주간 ≥ 오늘. 월요일에는 주간=오늘. 이번 주에 주기가 시작됐다면 주기=주간.
   - 초기 사용액은 날짜별 상세 내역이 아닌 합산 기록으로 저장합니다. 이후 목록에서 수정할 수 있습니다.
3. 문자 자동 처리 설명을 읽고 동의한 뒤 SMS 권한을 허용합니다. 거절하면 직접 입력으로 이용할 수 있습니다.
4. 과거 문자를 가져오지 않습니다. 설정 시점까지의 지출은 초기 금액에 포함하세요.

## 권한과 위젯

- 문자 수신 권한만 사용합니다. 과거 문자 읽기, 알림 접근, 인터넷, 연락처 권한은 없습니다.
- Android 권한 자체는 특정 발신번호로 제한되지 않습니다. 앱 내부에서 `1588-8100` 또는 국제 표기 `+8215888100`만 처리합니다.
- 자동 수집 동의와 Android SMS 권한이 모두 켜져야 합니다. 앱 화면에 상태가 표시됩니다.
- 홈 화면 빈 곳 길게 누르기 → 위젯 → **하루여유 시험판 4×2** → 추가. 앱의 위젯 추가 버튼도 사용할 수 있습니다.
- 삼성 홈 화면 배치나 글자 크기에 따라 위젯 높이를 늘려 주세요.
- 문자 반영·내역 수정 직후 위젯 갱신을 요청합니다. 자정·재부팅·시간대 변경·30분 정기 갱신도 사용합니다. OS 절전 상태에서 지연될 수 있어 ↻ 새로고침과 화면 갱신 시각을 제공합니다.
- 강제 종료한 앱은 다시 실행해야 수신이 재개될 수 있습니다. 자동 반영이 멈추면 권한, 자동 수집 동의, 절전/깊은 절전 앱 상태를 확인하세요.
- 알림 읽기 보조 경로는 시험판에서 제거했습니다. SMS와 알림의 이중 반영은 발생하지 않도록 한 경로만 씁니다. 카드 앱 푸시만 오고 SMS가 오지 않으면 자동 기록하지 못합니다.

## 계산 규칙

- 주기 순지출 = 주기 안의 승인·직접 지출 합계 − 주기 안의 취소 금액. 주기 잔액 = 예산 − 순지출. 초과 잔액은 음수 그대로 표시합니다.
- 오늘 아침 배정 = 오늘 지출 전 주기 잔액 ÷ 오늘 포함 남은 일수 (원 미만 버림).
- 오늘 사용 가능 = 아침 배정 − 오늘 순지출. 0 이상, 전체 남은 잔액 이하로 표시합니다.
- 10일 남고 아침 잔액 100,000원이면 오늘 10,000원. 오늘 5,000원을 쓰면 내일 `95,000÷9=10,555원`. 15,000원을 쓰면 내일 `85,000÷9=9,444원`.
- 이월액을 별도 누적하지 않습니다. 실제 잔액을 다음 날 나누므로 오늘 지출 중복 차감·이월 중복 가산을 피합니다.
- 이번 주 배정 = 주 시작 시 잔액 × 현재 주기 안의 이번 주 날짜 수 ÷ 주 시작부터 주기 끝까지 날짜 수. 이번 주 남음 = 배정 − 주간 순지출(0 이상, 전체 잔액 이하).
- 주간은 월요일~일요일이며 소비주기 경계에서 잘립니다. 주중 배정은 유지하고 다음 주에 다시 배분합니다. '필요 소비'가 아니라 상한을 돕는 배정값입니다. 일간·주간 수치는 다른 기간의 지표이므로 서로 더하지 않습니다.
- 새 소비주기에는 새 예산을 적용합니다. 이전 잔액을 넘기지 않으며 과거 내역은 삭제하지 않습니다.
- 취소는 취소 날짜의 음수 지출입니다. 이전 주기 결제의 취소도 현재 취소 주기에 반영하므로 순지출이 음수이거나 잔액이 예산보다 클 수 있습니다. 카드 청구액과 동일하다는 뜻은 아닙니다.
- 시작일·예산 변경은 보관된 기록을 새 범위로 즉시 다시 계산합니다. 초기 합산 기록의 실제 과거 결제 날짜는 알 수 없으므로 시작일 변경 뒤 검토하세요.

## 내역 확인·수정

- 인식된 문자는 확인·저장 버튼 없이 자동 반영됩니다.
- '최근 내역'을 눌러 날짜·금액·취소 여부를 수정하거나 삭제합니다. 최근 40건 외에 과거 내역 전체도 볼 수 있습니다.
- '누락 지출·취소 직접 추가'로 빠진 내역을 추가합니다. 부분 취소는 **돌려받은 금액만** 입력합니다.
- 금액이 여러 개이거나 형식이 불확실한 대상 문자는 '확인 대기'에 두고 잔액에 반영하지 않습니다. 검토 후 저장하거나 삭제하세요.
- 초기 설정 이전 시각의 늦게 온 문자는 초기 사용액과 중복될 수 있으므로 확인 대기입니다.
- 동일 원본 문자(PDU)의 재전달은 한 번만 반영합니다. 수정·삭제 후 재전달되어도 복구되지 않습니다.
- 같은 분·같은 금액이라도 원본 문자 정보가 다르면 별도 거래입니다. 완전히 동일한 원본 바이트의 두 수신은 재전달과 실제 두 거래를 구분할 수 없습니다. 새 타임스탬프로 재발송된 문자는 자동 중복 제거를 보장하지 못합니다.

## Galaxy A16 실제 확인 체크리스트

소액 실제 결제는 본인이 필요할 때만 진행하세요. 개발 테스트만을 위해 결제할 필요는 없습니다.

- [ ] 원본과 시험판이 동시에 열리고 원본 설정·기록·위젯이 그대로다.
- [ ] 초기 주기/주/오늘 금액이 중복 합산되지 않는다.
- [ ] 앱을 닫고 홈 화면에서 새 승인 SMS 수신 → 전체 잔액이 결제 금액만큼 감소하고 위젯이 갱신된다.
- [ ] 같은 분·같은 금액으로 실제 두 결제가 있었다면 두 건 모두 남는다.
- [ ] 전체 취소와 부분 취소는 문자에 적힌 취소액만큼 잔액이 증가한다.
- [ ] 카드 앱 알림만으로 금액이 추가되지 않는다. 대상 아닌 발신번호 문자도 추가되지 않는다.
- [ ] 모르는 형식은 확인 대기로 표시되고 자동 지출로 잡히지 않는다.
- [ ] 수정·삭제·누락 추가 후 앱과 위젯 금액이 일치한다.
- [ ] 자정 이후 어제의 남은 돈/초과 지출이 새 일일 허용액에 반영된다. 주기 시작일에는 새 예산이 적용되고 과거 기록은 남는다.
- [ ] 재부팅·화면 꺼짐·절전 상태에서 이후 SMS 수신과 갱신을 확인한다.
- [ ] SMS 권한 거절/철회와 자동 처리 동의 끄기에서 수집이 중단되고 직접 입력은 된다.

## 알려진 한계와 시험 범위

- 실기기·실제 롯데카드 문자·삼성 절전 정책은 사용자의 Galaxy A16에서 확인해야 합니다. 자동 테스트의 합성 예시는 실제 문자 형식 지원 증명이 아닙니다.
- 첫 시험판은 국내 원화 승인·취소의 보수적 문자 파서입니다. 해외·외화·RCS·MMS·카드 앱 푸시·문자가 없는 소액 결제는 보장하지 않습니다.
- SMS 알림 서비스가 활성화되어 있어야 합니다. 해당 서비스 가입 상태와 요금은 카드사에서 직접 확인하세요. 앱이 이를 신청하거나 비용을 발생시키지 않습니다.
- 취소와 원승인을 자동 연결하지 않습니다. 동일 거래가 새 문자로 재발송되거나 일괄 취소 메시지가 오면 수동 확인이 필요할 수 있습니다.
- 설정 완료 이후 수신부터 대상입니다. 강제 종료/권한 거절 동안 놓친 문자를 과거함에서 다시 읽지 않습니다.
- 휴대폰 날짜·시간대를 기준으로 계산합니다. 초기 합산값은 과거 개별 거래를 재현하지 못합니다.
- 앱 삭제·저장공간 지우기는 **시험판 데이터만** 없앱니다. 내보내기·서버 백업은 이번 버전에 없습니다. Android 자동 백업은 비활성화했습니다.
- 무료 시험판은 자동 만료되지 않습니다. 단기 검증 기간은 운영상 정하며 기록을 갑자기 차단하지 않습니다.
- 디버그 서명 시험용 APK입니다. 일반 판매·스토어 심사 통과·SMS 권한 정책 적합성은 이번 APK 제작으로 검증되지 않았습니다. 공개 출시 전에 별도 확인합니다.

## 시장 검증 기록 (선택, 서버 전송 없음)

7~14일 동안 설정 완료 여부, 실제 SMS 반영 성공/누락/오류 건수, 위젯을 본 날 수, 하루 사용 가능 금액이 지출 결정에 도움이 된 사례를 직접 기록하세요. 무료 설치만으로 유료 구매 의향이 검증되었다고 보지 마세요. 외부 모집·스토어 배포는 별도 승인 후 진행합니다.
